## Why Burnt

- **Glanceable** — your daily burn lives in the menu bar (macOS) or system tray (Windows); no terminal, no dashboard to open.
- **Accurate** — numbers match [`ccusage`](https://github.com/ryoppippi/ccusage) to the cent (it's bundled inside).
- **Self-contained** — no Node install, no dependencies, works offline. One command on either platform.
- **Yours to shape** — Minimal / Standard / Detailed dashboard styles, a daily budget bar, and four display modes for the menu bar / tray.

## Install

### macOS

#### Homebrew (recommended)

```bash
brew install mafex11/tap/burnt
```

That's it — no Homebrew tap step needed (the full path taps automatically). To update later:

```bash
brew upgrade --cask mafex11/tap/burnt
```

#### Manual download

1. Download **`Burnt.zip`** from the [latest release](https://github.com/mafex11/Burnt/releases/latest).
2. Unzip it and drag **`Burnt.app`** into `/Applications`.

#### First launch (one-time)

Burnt is ad-hoc signed (not notarized), so on first launch macOS may say *"Burnt cannot be opened because Apple cannot check it for malicious software."* This is expected. To open it:

- **Right-click** `Burnt.app` → **Open** → **Open**, or
- **System Settings → Privacy & Security → Open Anyway**

You only need to do this once. After that, the flame icon with today's spend appears in your menu bar and refreshes automatically.

No system Node.js or other dependencies are required — a self-contained Node runtime and `ccusage` are bundled inside the app.


That downloads the latest build to `%LOCALAPPDATA%\Programs\Burnt`, adds a Start Menu shortcut and launch-at-login, and starts Burnt in your system tray. Windows tray icons can't carry a text label, so Burnt renders today's spend *into* the icon (`$12`) and gives you the full dashboard on click — same features as macOS.

#### Manual download

1. Download **`Burnt-windows-x64.zip`** (~12 MB) from the [latest release](https://github.com/mafex11/Burnt/releases/latest/download/Burnt-windows-x64.zip). It contains `burnt.exe` and `ccusage.exe`, so no Node is required.
2. Unzip it wherever you like and run `burnt.exe`.

#### First run (one-time)

`burnt.exe` is unsigned, so on the manual path SmartScreen may say *"Windows protected your PC"*. Click **More info → Run anyway**. The one-liner unblocks the downloaded files for you, so it doesn't ask.

The popover is drawn with the **WebView2** runtime. It's preinstalled on Windows 11 and most Windows 10 machines; the installer fetches it silently if it's missing.

#### Update

Burnt checks GitHub releases and updates itself (turn it off in settings) — or just rerun the one-liner.

#### Uninstall

1. Quit Burnt from the tray menu.
2. Delete `%LOCALAPPDATA%\Programs\Burnt`.
3. Remove the `Burnt` value under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
4. Delete `%APPDATA%\Burnt` (settings).

## What it shows

Click the menu bar / tray icon for a breakdown:

- **Today / week / month / all-time** — cost in USD and token volume
- **Trend & pace** — how this week compares to last, and where today is heading
- **14-day sparkline** + a **12-week spend heatmap** — hover any day for its cost
- **By tool** — Claude vs Codex, color-coded
- **By model** — where the expensive tokens go (opus, sonnet, gpt-5, …)
- **By project** — which repo/directory is eating your budget
- **Cache savings** — an estimate of how much prompt caching saved you
- **Burnt Wrapped** — a shareable card of your month / all-time spend (copy or save as PNG)

## Settings (⚙)

- **Dashboard style** — *Minimal* (just the numbers + chart), *Standard* (+ tool split), or *Detailed* (everything)
- **Menu bar / tray shows** — Today $, Today tokens, Week $, or just the icon
- **Daily budget** — a progress bar that turns amber near your cap and red when over
- **Launch at login**

> **Billing note:** Burnt is built for **API (pay-per-token)** accounts, where the `$` is real money spent. It still works on Pro/Max/Team subscriptions — the token counts are exact — but there the `$` is the **API-equivalent value** of your usage (what it *would* cost on the API), not a bill. A dedicated subscription mode is planned.

## Requirements

**macOS**

- macOS 14 (Sonoma) or later
- Apple Silicon (arm64)

**Windows**

- Windows 10 (1809 or later) or Windows 11, x64
- WebView2 runtime — preinstalled on Windows 11 and most Windows 10; the installer adds it if missing

**Both**

- [Claude Code](https://github.com/anthropics/claude-code) and/or [Codex](https://github.com/openai/codex) usage logs in `~/.claude` / `~/.codex` (under `%USERPROFILE%` on Windows)

## How it works

On macOS, Burnt bundles a self-contained Node runtime plus a pinned copy of [`ccusage`](https://github.com/ryoppippi/ccusage) and runs `ccusage daily --json` (which reads your local `~/.claude` and `~/.codex` logs), then aggregates the result into a glanceable summary. All cost/pricing is owned by ccusage (LiteLLM pricing table); Burnt is the native menu bar / tray surface on top of it.

Pricing is always fetched live so the numbers match `ccusage` exactly. The menu bar / tray refreshes every 60 seconds and on every popover open. Nothing leaves your machine except ccusage's pricing-table fetch.

The Windows build is a Go port in [`windows/`](windows/) — same engine behaviour, driving a native tray icon and a WebView2 popover, and talking to the standalone `ccusage.exe` over the same ccusage JSON contract.

## Build from source

### macOS

```bash
git clone https://github.com/mafex11/Burnt && cd Burnt

# Run the engine test suite (needs Xcode for XCTest)
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test

# Build the signed, self-contained .app (downloads portable Node + ccusage)
./packaging/make-app.sh
open Burnt.app
```

Cutting a release (builds, zips, stamps the cask's sha256):

```bash
./packaging/make-release.sh
gh release create vX.Y.Z Burnt.zip -R mafex11/Burnt --title "Burnt X.Y.Z" --notes "…"
```

> Building requires `npm` + network (to vendor Node + ccusage) and Xcode (for the test suite). Neither is needed at runtime.

### Windows

Needs Go 1.25 (it cross-compiles from macOS or Linux too):

```powershell
cd windows
go build -ldflags "-H windowsgui" ./cmd/burnt
```

Then place `ccusage.exe` — from the npm package `@ccusage/ccusage-win32-x64@20.0.6` — next to `burnt.exe`, and run it.

## Project layout

```
Sources/UsageEngine/   Pure, tested Swift library: parse → classify → price → aggregate
Sources/Burnt/         SwiftUI MenuBarExtra app (thin UI over the engine)
packaging/             Icon generator, app-bundle + release scripts, Homebrew cask
Tests/                 Engine unit tests + integration smoke test
windows/               Go port for Windows: engine + system tray + WebView2 popover,
                       sharing the same ccusage JSON contract as the macOS app
install.ps1            One-line Windows installer (served over raw.githubusercontent.com)
site/                  Marketing site (Next.js static export)
```
